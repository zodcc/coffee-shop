# Кофейня «Зерно» ☕

Учебный проект: адаптивный лендинг (сайт-визитка) для локального бизнеса.

## 🛠 Технологии
* HTML5 (семантическая верстка)
* CSS3 (Flexbox, CSS Grid, медиа-запросы для адаптивности)
* JavaScript (валидация формы обратной связи)

## 📂 Структура проекта
* `index.html` — главная страница
* `css/style.css` — стили
* `js/script.js` — скрипт валидации
* `img/` — графика
